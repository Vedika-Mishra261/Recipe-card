# 🍕 Pizza Recipe Card

A simple and responsive **Pizza Recipe Card** webpage built using HTML5 and CSS3 as part of my Web Development Internship at Veda Technology.

This project displays a delicious pizza recipe with an image, ingredients, and step-by-step preparation instructions in an attractive and user-friendly card layout.

## 📌 Project Overview

The Pizza Recipe Card is a beginner-friendly frontend project created to practice semantic HTML, CSS styling, and responsive web design.

The webpage presents a pizza recipe in an organized format, making it easy for users to view the ingredients and follow the preparation steps.

## ✨ Features

- Attractive pizza recipe card design
- Pizza image with caption
- Recipe description

- Step-by-step preparation instructions

## 🍕 Recipe Details

### Pizza

A delicious homemade pizza prepared with a crispy base, flavorful tomato sauce, cheese, and fresh toppings.

### Ingredients

- Pizza base
- Tomato sauce or pizza sauce
- Mozzarella cheese
- Chopped onion
- Chopped capsicum
- Tomato slices
- Oregano
- Chilli flakes
- Salt to taste

### Preparation Steps

1. Prepare the pizza base.
2. Spread pizza sauce evenly over the base.
3. Add mozzarella cheese.
4. Arrange the vegetables and toppings.
5. Sprinkle oregano and chilli flakes.
6. Bake until the cheese melts and the base becomes crispy.
7. Slice and serve hot.

## 🚀 How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/pizza-recipe-card.git
   ```

2. Open the project folder in VS Code.

3. Open the `index.html` file.

4. Run the project using the **Live Server** extension.

5. Your Pizza Recipe Card webpage will open in the browser.
